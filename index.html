Open a FAD report file

      
Drop a THECB Financial Aid Database (FAD) report file anywhere on this page, or choose one. The explorer reads the HY2K header and EOF1 trailer, picks the FY 2025 or FY 2026 layout from the header, splits every student record into its data elements, and runs the edit checks from THECB’s FAD Report Manual, so you can find, fix and save problems before you upload to CBPass.

      
Files are read inside this browser tab. Nothing is uploaded.

Record layouts
A layout lists where each field starts and how many characters it takes. The built-in FAD layouts come from the File Layout section of THECB’s FAD Report Manual for FY 2025 and FY 2026. Add your own for a new reporting year or any other fixed-width report.

      
    

    

    

      Share layouts you’ve made
      

        
Layouts you make are saved in this browser only. Copy the export and send it to a colleague, who pastes it below and chooses Import. To build layouts into this file for everyone, paste the export between the office-layouts script tags near the top of the HTML file.
